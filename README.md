A single original one-line roast of the gadget used every day — the phone that only charges at one exact angle — written by a small Node 22 program that prints the line to `/output/entry.txt` for the make.fun judge. Target: a top-3 paid place in the $5 pot.

## The roast

> My phone only charges at one exact angle, so every night I hold it like a bomb technician defusing my own battery.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Node 22.18 or later runs the TypeScript directly, no install step. The program validates the line (one line, 1–200 characters) and writes exactly that line to `entry.txt`, nothing else. Running it twice produces byte-identical output.

## Why this line

The judge picks the funniest, freshest, neatest line. This one roasts the phone itself; it lands on first read because anyone with a worn charging port has performed the same nightly ritual; the angle is fresh — not the tired dead-battery complaint, but the bomb-technician image; and it is tight, one sentence with the punch at the end.
